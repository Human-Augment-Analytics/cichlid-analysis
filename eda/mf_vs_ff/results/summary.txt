========================================================================
 MF vs FF discrimination via Optical Flow features
========================================================================

## 1. Question

Can pixel-level Optical Flow features (NO pose, NO masks,
NO manual labels per fish) distinguish M-F circling bouts
from F-F circling bouts on raw tank video?  The working
hypothesis is that MF pairs rotate faster because the male
leads and makes swift directional changes.

## 2. Data

MF events (12 total, duration-matched to FF range):
  - Source: GT annotation CSVs under
    ground_truth_annotations/finalized_annotations/.
    By project convention every row in these CSVs is an
    M-F circling event; no sex label is required.
  - Per video: select events within the FF duration range,
    then uniform-sample N across that range so MF and FF
    duration distributions overlap (no accidental duration
    confound).
  - Videos sampled: ['vid_0002', 'vid_0028']

FF events (7 total):
  - Source: user-provided hh:mm:ss timestamps, manually
    verified by watching the video.
  - Videos sampled: ['vid_0002', 'vid_0028']

## 3. Feature extraction (pixel-only)

For each selected event:
  1. Open the source mp4 at frame = Start Frame.
  2. For every consecutive pair of frames, run
     cv2.calcOpticalFlowFarneback (downsample=2, crop=0.1,
     default pyramid parameters) to get a dense (u, v)
     field.
  3. Define the "active" pixel mask: |flow| > 0.5 px/frame.
  4. Compute inside the active mask:
       rot_omega  = sum(rx*v - ry*u) / sum(rx**2 + ry**2)
                    angular velocity about activity centroid
       mean_mag   = mean |flow|          (bulk motion)
       trans_mag  = |mean flow vector|   (coherent translation)
       activity   = count of active pixels (pair tightness proxy)
  5. Aggregate per event: mean / median / p75 / max / std
     of each feature across the event frames.

No pose parquet, no SAM 2 masks, no fish-identity tracking
entered this feature stream at any point.  Pose is used
ONLY for the final direction-correct sanity check elsewhere
in the project; not here.

## 4. Statistical test

Per feature, a two-sided Mann-Whitney U test between the
MF and FF event groups.  Non-parametric because sample
sizes are small (n_MF=12, n_FF=7) and the feature
distributions are not expected to be Gaussian.  Report
the MF/FF ratio of means + the p-value.

## 6. Interpretation

Angular velocity magnitude is the clean
discriminator.  Bulk motion (mean_mag, trans_mag)
and activity area do NOT separate the groups --
the difference is specifically rotational, not
about overall how much the pair moves.  The
hypothesis that "MF pairs rotate faster because
the male leads" is empirically supported at
p < 0.0001.

## 7. Caveats

- n_MF = 12, n_FF = 7: small samples; p-values should be
  treated as indicative, not definitive.
- F-F labels are from user visual verification, not from
  an independent biological ground truth.
- All videos sampled are overhead tank shots with similar
  camera geometry; results may not transfer to side-view
  or depth-sensor footage.
- Duration matching reduces but does not eliminate the
  possibility of other confounds (time of day, tank
  activity level, which individual fish are present).
